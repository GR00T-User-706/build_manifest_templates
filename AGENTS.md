# AGENTS.md

Read `docs/PROJECT_STANDARDS.md`, `docs/formats.md`, and `docs/placeholder-conventions.md` before changing templates.

- This repository contains starter templates and explanatory examples; it is not a package builder.
- Preserve native ecosystem syntax and distinguish formats that have different semantics.
- Do not invent package names, versions, checksums, URLs, dependencies, maintainer details, or licenses.
- Label placeholders and provisional examples clearly.
- Document the native validation/build command and exactly what it proves.
- Do not claim a template is release-ready merely because it exists.
- Preserve unrelated template content and history.
- For documentation-only changes, update the changelog without changing package implementation or inventing a version bump.
- Perform a read-only audit first and report unverified behavior explicitly.
